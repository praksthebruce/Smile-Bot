# Smile-Bot
The Repository Of all codes of My Slack Bot!

## Configuration

Create a local `Smilebot` file with the Slack credentials required by Socket Mode:

```text
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
```

The app token must be an app-level token with Socket Mode enabled. Keep this file private and revoke any tokens that have been exposed publicly.
